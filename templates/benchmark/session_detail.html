How EcoDep Measures Telemetry & Calculates Green Scores
1. Execution Time & CPU

Monitored using monotonic high-resolution timers (time.perf_counter_ns()) over multiple iterations with warm-up cycles. Process CPU load is sampled via psutil thread telemetry.

2. Memory, Energy & CO₂

Resident Set Size (RSS) and peak allocations are tracked via memory profilers. Energy is measured in Joules (Intel RAPL / hardware power model $E = P \cdot t$). Carbon emissions $\text{CO}_2\text{e}$ convert kWh using regional carbon grid factors.

3. Multi-Criteria Green Score

Computed using MCDM / TOPSIS multi-criteria optimization: $\text{Green Score} = w_e S_{\text{energy}} + w_t S_{\text{time}} + w_c S_{\text{cpu}} + w_m S_{\text{memory}}$, mapping lower footprints to scores up to 100.
